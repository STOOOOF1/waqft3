# مدينة الوقف

لعبة تعليمية ثلاثية الأبعاد في المتصفح لمراجعة مقرر **اقتصاديات الوقف والعمل الخيري** (مرحلة الماجستير).

مدينة بجوّ غروب ذهبي، فيها سبعة معالم لسبع وحدات. أمام كل معلم فوانيس دروسه، وعددها في المدينة كلها ثلاثون درسًا، هي أسئلة المقرر وأجوبته منقولة بنصها. يُضاء الفانوس بقراءة الدرس، ويُثبَّت بالإجابة عن سؤاله. وتُفتح بوابة كل معلم باجتياز اختبار الوحدة بنسبة ٧٠٪ فأكثر، وبعد فتح البوابات السبع تُمنح الشهادة.

## المحتوى

| | العدد |
|---|---|
| الوحدات (المعالم) | ٧ |
| الدروس | ٣٠ |
| أسئلة الفوانيس | ٣٠ |
| أسئلة اختبارات الوحدات | ٤٤ |
| المحاكيات التفاعلية | ١٦ (تصنيف، مقارنة، شجرة قرار، قرارات الناظر) |

**أدوات المراجعة قبل الاختبار:**
- **مراجعة سريعة:** عشرة أسئلة عشوائية من الوحدات التي تختارها.
- **دفتر الأخطاء:** يُضاف إليه كل سؤال تخطئ فيه، ويخرج منه حين تجيبه صحيحًا.
- **بطاقات الخلاصة.**

كل سؤال يحيل إلى رقم السؤال في المذكرة (س١…س٣٠)، لأن المذكرة بلا أرقام صفحات.

## التحكم

| | الحاسوب | الجوال |
|---|---|---|
| المشي | الأسهم أو WASD (و Shift للركض) | العصا أسفل الشاشة |
| تدوير الكاميرا | السحب بالفأرة، والعجلة للتقريب | السحب على الشاشة |
| فتح الفانوس أو البوابة | E أو Enter، أو النقر عليه | زر «افتح» |
| خريطة المنهج | M | زر الخريطة |
| مراجعة سريعة | R | زر المراجعة |

كل درس واختبار متاح من **خريطة المنهج** دون الحاجة إلى المشي. وإن تعذّر تشغيل الرسوم ثلاثية الأبعاد على الجهاز، تعمل اللعبة بالخريطة وحدها.

## حزمة المذاكرة (`study/`)

| الملف | ما فيه |
|---|---|
| `study/waqf-summary.pdf` | ملخص المقرر في ١٠ صفحات A4 بخط تجوال، بألوان موفّرة للحبر: جداول وخرائط ذهنية تغطي الأسئلة الثلاثين |
| `study/cards/index.html` | موقع بطاقات متدرّج: ١٠٠ بطاقة على ٤ مستويات (١٠ ← ٢٠ ← ٣٠ ← ٤٠)، وزر «تم» يحفظ التقدم، و«رابط تقدّمك» يعيدك إلى موضعك ولو مُسح حفظ المتصفح |

المستويات كلها مفتوحة. والإضافات التي ليست من نص المذكرة مكتوبة داخل إطار «لا تخلط» أو «★».

## التشغيل

```bash
python3 -m http.server 8765
# ثم افتح http://localhost:8765/
```

تحتاج اللعبة اتصالًا بالإنترنت لتحميل three.js 0.187 من cdnjs. ويُحفظ التقدم في المتصفح (localStorage).

## الملفات

| الملف | ما فيه |
|---|---|
| `index.html` | الواجهة وأنماط CSS (رموز الهوية في رأس الملف) |
| `js/content.js` | المحتوى، مولّد آليًا — لا يُعدَّل يدويًا |
| `js/learn.js` | طبقة التعلّم: الدروس، والمحاكيات، والاختبارات، والمراجعة، والخريطة، والرتب، والشهادة، والحفظ |
| `js/world.js` | المدينة ثلاثية الأبعاد (three.js) |
| `source/mat.txt` | نص المقرر المستخرج من ملف Word |
| `tools/extras.py` | الوحدات، والعناوين المختصرة، والأسئلة، والمحاكيات، والخلاصة |
| `tools/build_content.py` | يبني `content.js` من المقرر ومن `extras.py` |
| `tools/validate.js` | يتحقق من البنية، ومن أن كل فقرة في المقرر منقولة إلى اللعبة |
| `tools/smoke_test.js` | اختبار آلي على مقاس الحاسوب ومقاس الجوال |

## تعديل المحتوى

```bash
python3 tools/build_content.py source/mat.txt js/content.js
node tools/validate.js "$PWD/js/content.js" source/mat.txt
```
